# 🌿 Photosynthesis Explorer

Beranda interaktif untuk pembelajaran fotosintesis tingkat SD.

## Cara memasukkan ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html`.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`.
6. Simpan, lalu buka alamat GitHub Pages yang diberikan GitHub.

## Catatan
Font menggunakan Google Fonts (Baloo 2 + Fredoka), sehingga perangkat memerlukan koneksi internet untuk memuat font tersebut.
